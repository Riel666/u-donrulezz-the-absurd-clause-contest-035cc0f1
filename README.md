## What it does

`main.ts` writes a single line — an absurd clause hidden deep inside a terms-of-service agreement — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> 12.4 By accepting these terms, you grant the Company the right to borrow your dreams on alternate Tuesdays, returning them slightly used and in no particular order.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
